Приложения react состоят из комнпонентов.
Компоненты - это часть UI или UX интерфейса, со своей логикой и реализацией. Компонент может быть мал как кнопка, или огромен как целая страница.
Компоненты реакт являются функциями JavsScript, которые возвращают разметки. Пример:

function MyApp() {
    return (
        <button>Я - кнопка</button>
    );
}

Теперь, когда вы обьявили MyButton, вы можете расположить его в другой компонентю
export default function MyApp() {
    return (
        <div>
        <h1>Welcome to my app</h1>
        <ByButton />
        </div>
    );
}
